# Lens: structure

Look only at how the document is organised, not at whether its content is right.

- **Order:** problem and context before the proposal; the proposal before details; decisions
  before the reasons that can wait. A reader should not need a later section to follow an
  earlier one.
- **Headings:** each heading says what its section contains; levels are consistent; no section
  under a heading that doesn't fit it.
- **One idea per section:** sections that mix several topics, or one topic spread over several
  sections.
- **Missing sections** the document type normally has (a design without alternatives, risks or
  rollout; a report without findings or a summary; user stories without acceptance criteria).
- **Duplicates:** the same content in two places, which will drift apart.
- **Appendix material:** long tables, logs, raw data or reference detail in the main text that
  belongs in an appendix or behind a link.

Severity: blocker = the structure hides the main point or a required section is missing;
major = a section is out of order, duplicated or mixes topics; nit = heading wording or level.

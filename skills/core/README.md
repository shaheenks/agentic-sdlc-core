# skills/core

Global skills, registered in `config/skills.yaml` (folder name = frontmatter `name` = key).

| Skill | Tag | Purpose |
|---|---|---|
| `write-user-story` | general | Feature idea → agile user story with acceptance criteria |
| `test-case-gen` | engineering | Test cases (happy path, edge, failure) from a requirement, story or signature |
| `design-review` | engineering | Review a design for correctness, risks, operability and security (approvers and admins) |
| `egm-brainstorm` | general | Questions → options → a brief the user confirms; locks the team |
| `egm-document-flow` | general | Draft → Goldfish review → resolve → save document + review |
| `lens-zoom-out`, `lens-comprehension`, `lens-design-critic`, `lens-implementation-readiness` | goldfish-lens | Default Goldfish reviewer lenses |
| `lens-structure`, `lens-style` | goldfish-lens | Opt-in lenses for long or formal documents |

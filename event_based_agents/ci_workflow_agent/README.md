# ci_workflow_agent

The event-based agent for plans, implementation and pull request reviews.

**Phase 0 skeleton.** Agent Runtime deployment (later phase); locally `uv run sdlc-ci-workflow-agent`.

Build and test from this folder: `uv run pytest`.

# Why

First step of the GCP-native hosting design (docs/designs/gcp-native-hosting.md, decision D17, phase WN.1). Today `sdlc-mcp` is
public (invoker IAM disabled) and gated only by the Entra token. In the native stack only the agent's
identity (and the UI service account, for two HTTP routes) may reach the MCP server at all; the Entra token
still decides what each user may do.

# Requirements

- Modifies [NFR-SEC-010](../requirements/non-functional/NFR-SEC-010.md): adds "In the `native` environment the
  MCP server accepts calls only from allowed Google identities (Cloud Run invoker IAM); per-user access is still
  decided by the Entra token." Back to `draft`.

# Design

- [infra_gcp](../components/infra_gcp.md): `infra/gcp/native.tf`, gated by `var.native_enabled` (default false, so dev is untouched).
  `sdlc-mcp-native` reuses the MCP settings of `run.tf` (bundles, Cloud SQL socket, secrets, service account) and
  has invoker IAM on: no `allUsers`, no `invoker_iam_disabled`. Invoker bindings are added by CH-0014 (agent
  identity) and CH-0016 (UI service account).
- The Google ID token travels in `X-Serverless-Authorization`, which Cloud Run checks for IAM, so `Authorization`
  stays free for the Entra token. The MCP server code does not change.
- [config](../components/config.md): `config/env/native/` (README; optional, git-ignored `users.yaml`).
- [scripts](../components/scripts.md): `gcp_deploy.ps1 -EnvName native` (tfvars `native.tfvars`, the `config` step publishes the
  native bundle).
- External MCP clients (Antigravity) cannot reach an IAM-only service; they keep using dev until W6.

As built:
- `sdlc-mcp-native` lives in the same Terraform root and state as dev, behind `native_enabled` (on in
  `dev.tfvars`), because it shares dev's database, buckets, secrets, service account and config bundle. So there
  is no `native.tfvars`, no `config/env/native/` and no `-EnvName native`: the native stack is a hosting variant,
  not another tenant or config. The config and scripts components needed no change.
- The MCP service became `for_each` over `local.mcp_services` (`main`, `native`) with a `moved` block, instead of a
  copy in `native.tf`; each service advertises its own `MCP_PUBLIC_URL`. Output `mcp_native_url`.
- Terraform tests pin `invoker_iam_disabled = each.value.public`, the native entry `public = false`, and that no
  resource grants `allUsers` or `allAuthenticatedUsers`.

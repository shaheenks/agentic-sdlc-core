# Rules

## Rule Set

- [Commands](commands.md) - Every command for running, testing, ingesting, tracing, configuring and deploying, with the rules attached to each.
- [Configuration rules](configuration.md) - How access is declared in config/: resolution, tools, sources, teams, app roles, skill naming and validation.
- [Environments and endpoints](environments.md) - Development on localhost and the tunnel, GCP dev, hostnames as configuration, and who runs Terraform and deployments.
- [Runtime config](runtime-config.md) - How services load configuration at runtime: ConfigStore, bundles, activation, rollback and the GCP config store.
- [Security rules](security.md) - Authorization, token validation, block list, connections, artifacts, audit records and secrets.
- [Tenant accounts and enterprise tenants](tenants.md) - Test users, when the tenant admin account may be used, and keeping identity tenant-agnostic.
- [Repo structure and workspace conventions](workspace.md) - Where each component lives, and conventions for the uv workspace, ADK and MCP sessions, tests, data tables and the knowledge graph.
